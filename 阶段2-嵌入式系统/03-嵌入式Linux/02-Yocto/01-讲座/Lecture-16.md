## 官方资料（始终优先于随便找的教程）

- [Yocto Project Documentation](https://docs.yoctoproject.org/) — 针对特定 release 的流程与变量。
- [Yocto Project Quick Build](https://docs.yoctoproject.org/brief-yoctoprojectqs/index.html) — 得到第一个镜像的最短受支持路径。
- [BitBake User Manual](https://docs.yoctoproject.org/bitbake.html) — 需要精确语义时查阅。

## 整本书级别的深度（可选）

- *Embedded Linux Systems with the Yocto Project* — 讲求实用，常在你的第一次构建之后作为第二轮学习材料。

## 相关路线图说明

关于 **Jetson 专用**的量产 BSP 实践，参见 **阶段 4 方向 B** 中的 Jetson 平台模块 *Orin-Nano-Yocto-BSP-Production*；本课程刻意保持 **厂商中立**。
